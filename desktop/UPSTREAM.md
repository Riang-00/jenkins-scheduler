# Upstream foundation

The desktop shell originated from the Vite template in [tauri-ui](https://github.com/agmmnn/tauri-ui), scaffolded with create-tauri-ui 1.2.0 and the b0 shadcn preset. The scheduler adds its own workflow, native commands, navigation restrictions and local Python JSON bridge.

Dependencies include Tauri (MIT OR Apache-2.0), React and shadcn/ui (MIT), Base UI (MIT), Lucide (ISC), Inter (OFL-1.1) and CPython (Python Software Foundation License and included third-party licenses). Bundled license texts and dependency notices are in `docs/THIRD_PARTY_NOTICES.txt`; CPython also includes `runtime/LICENSE.txt` in the installed application.
